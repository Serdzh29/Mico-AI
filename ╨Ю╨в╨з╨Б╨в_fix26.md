# Mico AI — отчёт о правках (версия 2026.10.2000)

## 1. Автозапуск
Причина: Windows 11 хранит отдельный флаг «включено/отключено» для пунктов автозагрузки
(раздел `StartupApproved\Run`, его переключают Диспетчер задач и Параметры → Автозагрузка).
Mico проверял только ключ `Run`, поэтому при отключённом в Windows пункте программа показывалась
как включённая, но при входе в систему не запускалась.

Исправлено (`autostart.py`):
- статус читает флаг `StartupApproved` и показывает «выключено», если Windows его отключил;
- при включении флаг снимается; при выключении запись удаляется;
- при старте, если путь в `Run` указывает на несуществующий файл (переустановили в другую папку), путь обновляется.

Проверка на Windows: отключить Mico в Диспетчере задач → Автозагрузка, открыть Mico,
в настройках должно стоять «выключено»; включить в настройках — пункт снова активен, после перезагрузки Mico стартует сам.

## 2. Ошибка «Failed to remove temporary directory _MEI…»
Это сообщение загрузчика PyInstaller (сборка `--onefile`), оно появляется уже после закрытия программы:
загрузчик не смог удалить временную папку, потому что файлы в ней ещё заняты.

Исправлено (`main.py`): вместо обычного `sys.exit` программа закрывает базу данных, сбрасывает буферы
и завершается через `os._exit`, без очистки интерпретатора при работающих фоновых потоках.
Это снижает вероятность ошибки. Полностью устранить её можно сборкой `--onedir` (папка вместо одного файла),
но это меняет формат поставки, поэтому не применено.

## 3. Мёртвый код и ошибки
Проверки: компиляция всех модулей; поиск неопределённых имён; поиск неиспользуемых импортов,
модулей и функций (AST-анализатор); полный прогон `tests/run_all.py`.

Удалено:
- модули: `settings_io.py`, `updates.py`, `remover.py` (старый консольный скрипт удаления, заменён мастером установки);
- функции: `_OpenOnClick` (main.py), `restart_explorer` (winctl.py), `_write_remover` (installer.py),
  `verify_sha256` (updates.py), `recent_changes` и `wi_changes` (version.py),
  `glow_colors`, `subtitle_full`, `subtitle_seconds`, `ease_io`, `sweep_lengths` (intel.py);
- неиспользуемые импорты в `main.py`, `intel_ui.py`, `wichat.py`, `health.py`, `cleanup.py`, `capabilities.py`;
- тесты, проверявшие только удалённый код: `tests/test_beta_modules.py`, `tests/test_remover.py`;
  фрагменты в `test_features_v37.py`, `test_intel.py`.

Оставлено намеренно: `make_changelog.py` (инструмент разработчика, описан в CONTRIBUTING.md),
`all_canonical` в intent.py (используется тестом покрытия команд).

Исправлено: в `test_intel.py` была проверка строки `QToolButton` внутри импорта, а не работы функции;
заменена на проверку самих функций. Ошибок в коде, которые приводят к падению (неопределённые имена), не найдено.

## 4. Оформление: Windows 11, единый шрифт
- Шрифт: `Segoe UI Variable Text` (системный шрифт Windows 11) во всём интерфейсе; устаревшие упоминания «Inter» в комментариях исправлены.
- Палитра: нейтральные тона Fluent вместо бежевых и фиолетовых; отдельная функция `theme.fluent(dark)`.
- Скругления: 4 px для кнопок и полей, 8 px для карточек и окон чата (раньше 12–20 px).
- Кнопка «Сбросить» у каждой настройки стала тихой текстовой (вместо розовой).
- Кнопки выбора цвета (`theme.swatch_qss`): подпись чёрная или белая в зависимости от яркости цвета.
- Файлы: `theme.py`, `wichat.py`, `main.py`, `blob.py`, `sleep_island.py`.

Ограничение: стили проверены генерацией (нет лишних скобок, все значения подставлены), но визуально
не проверялись — на этой среде нет PyQt6 и Windows. Нужен просмотр на Windows.

## Версия
`2026.10.2000` (stable). Запись в `version.py`, `CHANGELOG.md` перегенерирован через `make_changelog.py`.

## Что проверить на Windows
1. `python tests/run_all.py` — все проверки должны пройти.
2. Сборка `build_exe.bat` → `dist\Mico.exe`.
3. Автозапуск: включить, перезагрузить ПК; затем отключить в Диспетчере задач и проверить статус в настройках.
4. Закрыть Mico несколько раз — проверить, появляется ли окно `_MEI`.
5. Просмотреть настройки, чат и кнопки на светлой и тёмной теме.
