# Как помочь Mico AI

Спасибо, что хочешь помочь! Ниже — как запустить проект, проверить изменения и отправить их.

## Запуск проекта

- Нужен Python 3.10 или новее. Для работы самой программы — Windows 10/11.
- Установка зависимостей: `pip install -r requirements.txt`.
- Для запуска из исходников: `python main.py` (или `Mico.bat`).

## Тесты

```
python tests/run_all.py
```

Тесты работают **без Windows и без моделей**: системные вызовы и модули Windows подменяются. Они же запускаются в GitHub Actions на каждый push и pull request.

## Правила

- **Без новых зависимостей** без обсуждения в Issue.
- **Язык:** комментарии, сообщения пользователю и документация — на русском.
- **Не коммить личное:** `config.json`, журналы (`*.log`), модели, ключи, `key.bin`, файлы истории.
- **Новая функция — с тестом** в `tests/`. Если тест нельзя написать без Windows, опиши в pull request, как проверить вручную.
- **Версия и история:** правь `version.py` (добавь запись в `CHANGELOG`), затем запусти `python make_changelog.py` — `CHANGELOG.md` создаётся из `version.py`, вручную его не редактируй.
- **Переключатели Windows** описываются в `components.py`. Всё, что меняет систему, требует подтверждения UAC через `W.run_elevated`, а опасные переключатели получают предупреждение `note=`.
- **Пароли и данные пользователя** в логах не сохраняются. Перед отправкой проверь, что в тестах и примерах нет реальных путей, имён и ключей.

## Pull request

1. Сделай ветку от `main`.
2. Запусти `python tests/run_all.py` — все проверки должны пройти.
3. Заполни шаблон pull request: что изменилось, как проверено, есть ли запись в `version.py`.
4. Для ошибок в программе открой Issue по шаблону.

Вопросы по безопасности — не в Issues, см. [SECURITY.md](SECURITY.md).
