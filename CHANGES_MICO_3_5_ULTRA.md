# Mico-3.5-Ultra: что изменено

1. Новая модель **Mico-3.5-Ultra** (группа «Mico-3.5» в меню и настройках) → GigaChat-3-Ultra (так в API Сбера отвечает Ultra 3.5). Старый id `ultra3` автоматически ведёт в `ultra35`.
2. Меню выбора модели: фиксированная ширина, перенос длинных подписей, панель не выходит за край экрана (`ui/modelpicker.py: place_near`).
3. «Как открывать чат» убрано из настроек: чат всегда панелью сбоку (`mico.py: side_mode`, `assist/chat.py`, миграция `ui_layout = 3`).
4. Ответ не обрезается: облако получает запас 32000 токенов (при отказе 16000 → 8000 → без лимита), локальный запасной вариант — 4096; в системной подсказке — «пиши код целиком»; лимит системной подсказки для облака 6000 символов.
5. Стили общения: помимо подсказки в конце системного сообщения и температуры, короткое напоминание стиля добавляется в конец вопроса (`CHAT_STYLE_NUDGE`); творческий стиль важнее настроек тона и длины.
6. Анимация «думаю»: `ThinkingSteps` в чате — список шагов (значок, текст, линия-соединитель) появляется по очереди, активный шаг переливается, внизу дышащий шар; шаги задаются через `set_steps`. Раньше был `ThinkingPulse` (шарик с искрами) и орбита искр над головой Mico вместо трёх точек.

Проверено на Linux: тесты test_gigachat, test_chat_style, test_uilayout, test_winter. Окна Qt и сам GigaChat (нужен ключ) здесь не запускались — проверь на Windows 11.
7. **Харнес** (`core/harness.py`): постоянное состояние на диске (`%APPDATA%\Mico\harness_state.json`) — факты, задачи, журнал действий, сжатая сводка; общее для чата, голоса и Telegram. В запрос к модели попадает только нужная выжимка (бюджет 900 символов). Защита: лимит шагов (`agent_max_steps`, до 24), стоп при повторе действия, пометка «в работе» после сбоя. Память фразами: «запомни, что…», «забудь…», «что ты помнишь», «добавь задачу…», «мои задачи», «задача выполнена N». Пароли, ключи и номера карт не запоминаются.
8. **Telegram** (`core/telegram_bridge.py`): бот напрямую опрашивает api.telegram.org. Токен — в Windows DPAPI (`telegram.bin`). Подключение одноразовым кодом из настроек (вкладка «Агент»), дальше бот слушает только ваш личный чат. Изменения ПК — по «да» кнопками. Команды: /screen, /stop, /tasks, /memory, /status, /unpair. Прокси — в настройках (нужен `requests[socks]`).
Тесты: `tests/test_harness_telegram.py` (7 проверок, проходят).
9. **Mico-4** (`llm/cloudru.py`): новая модель в группе «Mico-4», GigaChat 4 708B-A41B через cloud.ru Foundation Models (`https://foundation-models.api.cloud.ru/v1`, модель `GigaChat/GigaChat-4-708B-A41`, OpenAI-совместимый формат). Нужен отдельный ключ cloud.ru: поле «Ключ cloud.ru» в настройках, хранится в защищённом хранилище Windows. Режим рассуждения включается только для сложных просьб (`Brain._wants_reasoning`), простые отвечают сразу. Ответ не обрезается (запас токенов с откатом). Остальные модели по-прежнему идут напрямую через ключ GigaChat.
10. Сбер отказался от названия Ultra, поэтому модель называется просто **Mico-4** (семейство 4 поколения, id `mico4`, старый `ultra4` ведёт в неё). Это основная модель по умолчанию (`cloud.DEFAULT_MODE`); один раз при запуске выбор в чате переключается на Mico-4 (`cloud_default_ver = 2`). Если ключа cloud.ru нет или cloud.ru недоступен, а ключ GigaChat есть, отвечает Mico-3.5-Ultra (`cloud.LAST["downgraded"]`), иначе показывается понятная причина.
11. Меню выбора модели прокручивается и не заезжает на Mico сверху (`ModelMenu.fit`, `MASCOT_ZONE`). Если Mico-4 недоступна, цепочка запасных: Mico-3.5-Ultra → Mico-3-Pro → Mico-3-Lite (раньше при ошибке прав на Ultra ответа не было вообще). Если модель не ответила, а ответ строится по поиску, в тексте теперь причина и пометка «это не ответ модели».
12. Исправлена ошибка «'Brain' object has no attribute '_style_temperature'»: при добавлении `_wants_reasoning` потерялась строка `def _style_temperature`. Добавлен тест `test_brain_has_all_reply_helpers`.
13. Встроенный ключ cloud.ru для Mico-4 (`llm/builtin_key.py: BUILTIN_CLOUDRU_KEY`). Свой ключ из настроек главнее встроенного. Ключ лежит в программе открыто; при утечке отзовите его в cloud.ru и подставьте новый.
