# CLAUDE.md

## О проекте
Mico AI — локальный ИИ-компаньон для Windows 11: округлый 3D-персонаж (blob) на рабочем столе.
Работает офлайн: одна текстовая GGUF-модель через встроенный llama-cpp, голос через Vosk (распознавание) и Piper (синтез).
Умеет открывать программы и сайты, управлять громкостью, яркостью, темой, сохранять скриншот по запросу, отвечать на вопросы и помнить разговор.
Все данные остаются на ПК. Опасные действия (выключение, службы, PowerShell) выполняются только после подтверждения «да».

Ключевые модули (папка mico/, файлы разложены по пакетам; точка входа — mico.py):
- core/ — мозг и речь: brain.py (главный цикл ответа, выбор модели, история), dialog.py, memory.py, phrase.py, typo.py
- win/ — команды и действия над Windows: osagent.py (каталог, разбор ответа модели, проверка просьбы), commands.py, agent.py, system.py (бывш. winctl)
- ui/ — интерфейс и персонаж: blob.py, widgets.py (бывш. components), theme.py, controls.py (бывш. switch_ui)
- assist/ — режим Mico AI: intel.py (логика), ui.py (бывш. intel_ui), chat.py (бывш. aichat)
- llm/ — модели: engine.py (бывш. local_llm), cloud.py (бывш. cloud_api), catalog.py, store.py
- voice/ — голос: control.py (бывш. voice_ctl), tts.py, stt.py, models.py
- web/ — интернет: find.py (бывш. webfind), search.py, weather.py
- data/ — память и фоновые журналы: storage.py, reminders.py, tracker.py
- setup/ — установка и обновления: installer.py, autostart.py, updatecheck.py
- i18n/ — перевод на английский; русский остаётся основным языком
- tests/ — тесты; часть из них требует Windows

Текущая версия — 2026.10.x. Сборка установщика на английском, главное приложение пока по умолчанию русское.
RHVoice удалён полностью; голоса только Piper.

## О владельце проекта
Разработчик-любитель, пишет по-русски. Делает Mico AI сам и тестирует на Windows 11.
Ставит задачи по шагам и часто присылает архивы проекта. Ценит, когда ответ короткий и по делу.

## Как работать с кодом
- Отвечай по-русски. Комментарии и пользовательские строки в коде — тоже по-русски, если нет явной просьбы про английский.
- Прежде чем менять поведение, найди причину в коде; не добавляй функции без просьбы.
- Не ломай существующие тесты. Тесты запускаются скриптом-раннером: pytest на этой машине может быть недоступен.
- Всё, что меняет систему пользователя, должно требовать подтверждения.
- Не выдумывай персональные данные владельца; сохраняй в архиве только то, что нужно проекту.
- Windows-поведение нельзя проверить на Linux: так и говори в ответе.

## Как добавить действие на компьютере (osagent)
1. Запись в CATALOG (win/osagent.py): risk (OPEN — без «да», CHANGE/DANGER — с «да»), args, about.
2. GROUND: слова в просьбе, без которых действие не выполняем (защита от выдумок модели).
3. describe() и UNDO_NOTE: фраза для подтверждения и честное «можно ли отменить».
4. execute(): вызов нужного модуля. Работает только на Windows, поэтому проверку пишем на чистой логике.
5. Тесты в tests/test_stage1.py (образец): разбор ответа модели, подтверждение, проверка просьбы.
Мессенджеры и поиск по файлам пока вне каталога: им нужны вопросы пользователю во время шагов (agent.Runner).
