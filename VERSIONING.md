# Как называются версии

Номер выпуска: **ГГГГ.ММ.ДДNN**, например `2026.10.1305`. ДД — день выпуска, NN — порядковый номер в этот день.

## Срочные исправления

Если после выпуска нужно срочно исправить ошибку при запуске, установке или в работающей функции, выпускаем исправление с буквой после номера:

- `2026.10.1305(a)` — первое срочное исправление после 1305;
- `2026.10.1305(b)` — второе, и так далее по буквам английского алфавита.

Буква не меняет дату и не сдвигает следующий номер: после `(b)` следующий обычный выпуск получает номер на один больше.

## Теги на GitHub

Скобки в названиях тегов неудобны, поэтому тег пишем без них: `v2026.10.1305a`. Проверка обновлений в программе понимает оба вида.

## Когда выпускать исправление

- ошибка при запуске или установке;
- сломана функция, которая есть в стабильной версии;
- риск потери данных.

Функции из беты не чинятся срочными исправлениями: они ждут следующего цикла бета-тестирования.
