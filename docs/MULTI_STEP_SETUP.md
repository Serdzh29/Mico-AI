# Инструкция по установке и запуску новых функций Mico AI

## Что добавлено

1. **Мессенджеры** — отправка сообщений в Telegram, MAX, WhatsApp, Discord
2. **Браузер с кликами** — клик по N-му результату в YouTube и Google
3. **Офисные программы** — запись в Word/Excel/Блокнот с поиском через Groq API

## Установка зависимостей

```bash
pip install pywinauto>=0.6.8
```

или просто:

```bash
pip install -r requirements.txt
```

## Примеры команд

### Мессенджеры
- "открой телеграм и напиши маме привет"
- "открой MAX и напиши мамуле: как дела?"
- "запусти WhatsApp и отправь Саше доброе утро"
- "открой Discord и напиши другу: пошли играть"

### Браузер
- "открой ютуб и включи первое видео"

- "найди в гугле Python tutorial и нажми на второй результат"

### Офисные программы
- "открой ворд и напиши про искусственный интеллект"
- "запусти блокнот и создай инструкцию по Python"
- "открой эксель и напиши про историю России"

## Как это работает

1. **brain.py** — добавлена проверка на многошаговые команды перед режимом агента
2. **multi_step.py** — координатор, который разбирает команды и запускает нужный сценарий
3. **messenger.py** — обновлён, добавлен Discord
4. **browser.py** — новый модуль для кликов по результатам через UI Automation
5. **office.py** — новый модуль для работы с офисными программами + Groq API

## Особенности

- Все сценарии выполняются в **фоновом потоке**, не блокируя основной интерфейс
- Используется **Groq API** для поиска информации (встроенный ключ уже есть в cloud_api.py)
- Мессенджеры работают через **универсальный поиск** (Ctrl+F) и Enter
- Браузер использует **UI Automation API** для надёжных кликов
- Word/Excel оформляются через **COM API** (красиво), Блокнот — через буфер обмена

## Проверка

Запусти Mico AI и скажи:
```
открой блокнот и напиши про Python
```

Mico должен:
1. Сообщить "Запустил сценарий"
2. Получить информацию через Groq API
3. Открыть Блокнот
4. Вставить текст

## Возможные проблемы

1. **pywinauto не установлен** — установи: `pip install pywinauto`
2. **pyautogui не установлен** — установи: `pip install pyautogui` (используется в office.py и multi_step.py)
3. **Мессенджер не открывается** — проверь, что .exe файл в PATH или укажи полный путь
4. **UI Automation не находит элементы** — возможно, браузер не успел загрузиться (увеличь время ожидания в browser.py)
