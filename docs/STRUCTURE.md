# Структура проекта Mico AI

## Корень — только то, что нужно для запуска и сборки
- `mico.py` — точка входа приложения.
- `Mico.spec`, `build_exe.bat`, `Mico.bat`, `Mico.manifest` — сборка и запуск `Mico.exe`.
- `requirements.txt` — зависимости Python.
- `README.md`, `PRIVACY.md`, `CHANGELOG.md`, `BACKLOG.md`, `LICENSE` — главные документы, на них ссылается программа и тесты.
- `assets/`, `data/`, `knowledge/` — ресурсы, которые попадают в сборку (пути прописаны в `Mico.spec` и `release.yml`, не переименовывать).

## Код приложения (пакеты)
- `core/` — мозг и речь: ответы, диалог, память, фразы, опечатки.
- `win/` — действия над Windows: команды, агент, приложения, браузер, мессенджеры.
- `ui/` — интерфейс и персонаж: чат, настройки, кнопки, темы, Mico.
- `assist/` — режим Mico AI: логика и окно чата.
- `llm/` — модели: локальный движок, облачные ключи, каталог моделей.
- `voice/` — голос: распознавание, синтез, голосовое окно.
- `web/` — интернет: поиск, погода, поиск в браузере.
- `data/` — хранилище, напоминания, журнал активности.
- `setup/` — установка, автозапуск, проверка обновлений, версия.
- `i18n/` — английский перевод интерфейса.
- `bench/` — замеры скорости моделей.
- `tests/` — тесты (запускаются `tests/run_all.py`).

## Документы
- `docs/` — вклад в проект, безопасность, правила версий, инструкция по установке и история отчётов.

## Прочее
- `tools/` — вспомогательные скрипты (очистка Mico вручную).
- `.github/` — шаблоны задач и сборка релиза.
