# Windows 11 26H2 и инсайдерские сборки

Факты ниже взяты из официальных страниц Microsoft: блог Windows Insider, центр сообщений Microsoft 365 и таблица жизненного цикла Microsoft Learn. Проверено на 13 октября 2026. Если что-то из этого устарело, смотри актуальные страницы Microsoft.

## Windows 11 26H2: что известно

Версия 26H2 вышла для всех подходящих устройств 29 сентября 2026. Это подтверждено сообщением Microsoft MC1482225 (центр сообщений Microsoft 365). Установка доступна на ПК с Windows 11 25H2 и 24H2, поставка идёт поэтапно и расширяется в следующие недели.

Главное отличие от прошлых обновлений: 26H2 приходит как пакет включения (enablement package). Windows 11 24H2, 25H2 и 26H2 используют одну общую ветку обслуживания и одну кодовую базу, поэтому новые функции уже есть в системе и активируются одной перезагрузкой. Размер загрузки маленький, полная переустановка не нужна.

Устройства на Windows 11 26H1 (например, на процессорах Snapdragon X2 для ПК на Arm) на 26H2 перейти не могут: 26H1 построена на другом ядре Windows. Установка 26H2 сбрасывает срок поддержки версии.

Некоторые функции, которые в 25H2 были выключены по решению Microsoft или организации, в 26H2 включены по умолчанию (по формулировке Microsoft в центре сообщений).

Источник: Microsoft, центр сообщений Microsoft 365, сообщение MC1482225 от 29 сентября 2026 (зеркало: mc.merill.net/message/MC1482225). Блог Windows Insider, запись от 19 июня 2026 (blogs.windows.com/windows-insider/2026/06/19/announcing-new-builds-for-19-june-2026-26h2-for-experimental/).

## Как проверить свою версию Windows 11

Текущую версию и сборку можно посмотреть в «Параметры → Система → О системе» или командой `winver`. В строке «Версия» показан номер вида 26H2 или 25H2, сборка указана рядом. Так же проверяет и Mico: скажи «какая у меня версия windows».

Источник: Microsoft, блог Windows Insider, запись от 19 июня 2026 (blogs.windows.com/windows-insider/2026/06/19/announcing-new-builds-for-19-june-2026-26h2-for-experimental/): там описан путь «Параметры → Система → О системе» и команда winver.

## Как получить 26H2

Для обычного пользователя, на устройстве с 25H2 или 24H2, путь такой: «Параметры → Центр обновления Windows». Если 26H2 уже доступна, там появится предложение её скачать и установить. Установка идёт в одну перезагрузку. Если предложения нет, обновление ещё не дошло до твоего устройства: его раскатывают поэтапно.

Организации могут разворачивать 26H2 через политики Центра обновления Windows, WSUS, Intune, Windows Autopatch и каталог Microsoft Update.

Источник: Microsoft, сообщение MC1482225 от 29 сентября 2026; блог Windows Insider от 27 августа 2026 (blogs.windows.com/windows-insider?p=179146) про путь «Параметры → Центр обновления Windows» через механизм, который Microsoft называет «seeker».

## Инсайдерские каналы Windows 11

Программа Windows Insider делит тестовые сборки на каналы. Официальные названия на 19 июня 2026:

- **Beta** — основной тестовый канал. Для 25H2 на июнь 2026 была сборка 26220.8690.
- **Experimental** — канал, где впервые появилась 26H2. Туда переходит бывший канал Dev.
- **Release Preview** — предварительный просмотр перед выпуском. Туда попадают сборки, которые почти готовы к публике.
- **Future Platforms** — сборки серии 29600 (Canary). Это не версии Windows 11.

Перейти между каналами можно в «Параметры → Центр обновления Windows → Программа предварительной оценки Windows». Вернуться с Experimental на Beta можно в любой момент, переустанавливать систему не нужно.

Источник: Microsoft, блог Windows Insider, запись от 19 июня 2026.

## Сборки 26H2 в инсайдерских каналах

- **19 июня 2026:** 26H2 впервые появилась для канала Experimental, сборка 26300.8697. Для 25H2 в бете была 26220.8690.
- **27 августа 2026:** 26H2 выпущена в канал Release Preview, сборка 26300.9278. Установка через механизм «seeker» в Центре обновления. Для организаций доступна через политики и WSUS. ISO-образы тоже обещали на сайте программы.

Номер сборки, с которой 26H2 вышла публично, в официальных источниках, которые я нашёл, не подтверждён однозначно: встречаются 26300.9457 и 26300.9550. Не называй номер как окончательный, пока его не проверишь на странице Microsoft.

Источник: Microsoft, блог Windows Insider, записи от 19 июня и 27 августа 2026 (blogs.windows.com/windows-insider?p=179146).

## Сроки поддержки Windows 11

- **24H2 (домашние версии и Pro):** обновления заканчиваются 13 октября 2026. Эта дата указана сноской в блоге Windows Insider от 27 августа 2026. В таблице Microsoft Learn стоит 14 октября 2026, в 06:59 по тихоокеанскому времени. Разница в день связана с часовыми поясами; для пользователя ориентир один: последние обновления приходят в эти дни.
- **25H2 (домашние версии и Pro):** обновления заканчиваются 13 октября 2027 по таблице Microsoft Learn.
- **26H1:** только для новых устройств на Arm, по таблице поддерживается до 15 марта 2028 для домашних версий и Pro.
- **26H2:** срок поддержки в официальной таблице, которую я нашёл, не подтверждён. Сторонние сайты называют 10 октября 2028 для домашних версий и Pro, но это не проверено по странице Microsoft. Не называй эту дату как точную.

Источники: блог Windows Insider от 27 августа 2026 (сноска про 24H2); Microsoft Learn, страница жизненного цикла Windows 11 Home and Pro (learn.microsoft.com/lifecycle/products/windows-11-home-and-pro).

## Что пока не подтверждено Microsoft

Некоторые материалы о 26H2 пишут о новых функциях: Copilot в проводнике, новое окно «Выполнить», ИИ в диспетчере задач, «агент» в параметрах. В официальных источниках, которые я нашёл, этих функций не перечислено. Если спросят о них, отвечай, что по официальным данным Microsoft список новых функций 26H2 не опубликован, и предложи проверить страницу «Что нового в Windows 11, версия 26H2» на learn.microsoft.com.
