## Hyper-V
Встроенная виртуализация Windows: позволяет запускать виртуальные машины. Нужна разработчикам и тем, кто тестирует системы. Обычным пользователям, как правило, не нужна. Включается с правами администратора, после включения нужна перезагрузка. Может конфликтовать со сторонними программами виртуализации.

## Подсистема Windows для Linux (WSL)
Позволяет запускать Linux-команды и программы внутри Windows без отдельной виртуальной машины. Удобна для разработки. Включается с правами администратора; часто нужна перезагрузка.

## Платформа виртуальных машин
Базовый компонент для WSL 2 и песочницы. Отдельно обычно не нужна, но без неё WSL 2 и песочница не работают.

## Песочница Windows (Windows Sandbox)
Одноразовое изолированное окружение Windows. Удобно, чтобы проверить подозрительную программу: при закрытии всё удаляется. Доступна не во всех редакциях Windows (обычно в Pro и выше). Требует включённой виртуализации в BIOS.

## .NET Framework 3.5
Старая версия платформы .NET. Нужна некоторым старым программам и играм. Если программа просит её установить, включи этот компонент. Для новых программ не требуется.

## Протокол SMB 1
Очень старый сетевой протокол общего доступа к файлам. Считается небезопасным и не рекомендуется включать, если нет конкретного старого устройства, которое без него не работает.

## Клиент Telnet
Старая программа для удалённого доступа к командной строке. Сейчас почти не используется: вместо неё берут SSH. Оставлять выключенным безопасно.

## Печать в PDF
Виртуальный принтер: «печатает» документ в файл PDF. Удобен, если нет физического принтера и нужно сохранить документ в PDF.

## Проигрыватель Windows Media
Старый медиаплеер Windows. В новых версиях заменён приложением «Кино и ТВ» и «Groove». Нужен только старым программам, которые ожидают его компоненты.

## Служба поиска Windows
Индексирует файлы, чтобы поиск работал быстро. Если выключить, поиск станет медленнее, но не сломается.

## Диспетчер печати
Служба, без которой не работает печать. Если выключить, принтеры перестанут печатать. Выключать можно только если точно не используешь принтер.

## Удалённый реестр
Позволяет редактировать реестр этого компьютера с другого компьютера по сети. Для обычного пользователя не нужен, и его лучше держать выключенным из соображений безопасности.

## SysMain (Superfetch)
Заранее загружает часто используемые программы в память. На SSD эффект почти незаметен, на старых жёстких дисках помогает. Выключать не обязательно.

## Телеметрия (DiagTrack)
Служба отправки диагностических данных в Microsoft. Выключение уменьшает передаваемые данные. Некоторые функции и диагностика ошибок могут работать хуже. Обновления Windows при этом продолжают работать.

## Служба факса
Для отправки и приёма факсов через модем. Большинству пользователей не нужна.

## Служба геолокации
Позволяет программам узнавать местоположение компьютера. Выключение отключает геолокацию для Windows и программ. Погода по геолокации в Mico перестанет определять место автоматически.

## Удалённый рабочий стол
Позволяет подключаться к этому компьютеру с другого устройства. Если включено, убедись, что установлен надёжный пароль. Для обычного использования обычно выключено.

## Защитник Windows (защита в реальном времени)
Встроенный антивирус: проверяет файлы и программы при запуске. Отключать его без необходимости не рекомендуется. Если включена защита от подделки (Tamper Protection), Windows не даст выключить защиту программно. Тогда это нужно сделать вручную в «Безопасность Windows».

## Брандмауэр Windows
Сетевой экран, который контролирует входящие и исходящие соединения. Выключать не рекомендуется: без него компьютер менее защищён в публичных сетях.

## Быстрый запуск
Ускоряет включение компьютера за счёт сохранения части состояния ядра при выключении. Может мешать, если на компьютере установлено две системы или нужен полный сброс. Включает и выключает права администратора.

## Режим гибернации
Сохраняет всё состояние компьютера на диск и полностью выключает его. Занимает место на диске, размером примерно с объём ОЗУ. Нужна для быстрого запуска. Если место на диске важно, гибернацию можно отключить.

## Запись игр (Game DVR)
Позволяет записывать игровой процесс через Game Bar. Работает в фоне и может немного снижать производительность. Если записи не нужны, можно выключить.

## Игровой режим
Старается выделить больше ресурсов запущенной игре и снизить фоновые задачи. Обычно полезен, но эффект зависит от компьютера.

## Обмен кнопок мыши
Меняет назначение левой и правой кнопок. Удобно для левшей. Не влияет на программы.

## Живые субтитры
Показывают субтитры для любого звука, который воспроизводит компьютер. Работают офлайн, но для первого запуска может понадобиться скачать языковой пакет.

## Лупа
Экранная лупа для увеличения части экрана. Сочетание Win + плюс включает её.

## Экранная клавиатура
Виртуальная клавиатура на экране. Полезна, если физическая клавиатура не работает или нужно вводить текст мышью.
